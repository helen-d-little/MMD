# MMD

In December 2025 we started working through the Stanford Online CSX0002 Mining Massive Datasets course. I seem to remember a comment about it taking ~8 weeks to complete. Now about 40 weeks in we are around 30% through the course - but we slog on. 

This repo will be periodically updated with notes and ideas derived from the course, no homework but hopefully some interesting implementations and a way for me to explore what the course has to offer.
